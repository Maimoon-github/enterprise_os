The sequence below preserves the attachment-defined **Model A**, existing persistence/repository boundaries, and the four distinct Layer-4 systems of record. Layer 4 remains accessible through the **MCP Data Gateway**, while Layer-5 workers retain mediated read-only access through IE.  The existing backend already provides the core RAG, MCP, CMS, persistence, memory-promotion, telemetry, provenance, security, and test seams that this plan extends rather than duplicates.
